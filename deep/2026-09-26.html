    背景與核心衝擊

    荷蘭政府正式宣佈啟動「主權作業系統計畫」，以 NixOS 為核心基底開發開源替代方案，目標在三年內完成核心行政系統、資料中心與終端裝置的微軟 Windows 與 Office 全面遷移。這不是單純換個作業系統，而是歐洲公部門首次在國家層級以「可重現建構」特性的 NixOS 為標準，切斷對微軟專有授權體系、專有格式與 Azure 雲端原生服務的結構性依賴。事件核心衝擊在於三點：一、授權成本歸零，荷蘭中央政府每年節省超過 1.2 億歐元的微軟 E5/E3 訂閱費；二、資料主權回歸，所有系統組態、套件版本、編譯參數皆以宣告式程式碼管理，消除供應商鎖定風險；三、示範效應擴散，德國史列斯威格-霍爾斯坦邦、法國公部門開源專案、義大利國防部同步啟動評估，預估未來 24 個月將有超過 15 個歐盟成員國跟進 PoC。對台灣供應鏈而言，這意味著工業電腦、嵌入式主機板、邊緣運算閘道器等硬體層需求將從「支援 Windows/Linux 雙系統」轉向「原生 NixOS 驅動認證、不可變基礎設施部署、SBOM 軟體物料清單自動產出」的高規格要求，單機邊緣裝置 BOM 成本預估上升 8 到 12％，但系統整合商單專案毛利可望提升 5 個百分點以上。

    傳導路徑圖解

    新聞事件觸發點在於荷蘭內閣部長會議通過遷移決議，隨即傳導至歐盟數位主權工作小組，帶動歐盟委員會修訂《互操作性歐洲法案》附件，將 NixOS 列入參考架構。全球系統整合商如 Atos、Capgemini、T-Systems 同步成立 NixOS 交付中心，向上游晶片廠與主機板廠下達驅動移植需求單。台灣供應鏈第一層為嵌入式主機板廠，需在 Intel Core Ultra、AMD Ryzen Embedded、NXP i.MX 9 系列平台上完成 NixOS 即時核心、ZFS 根檔案系統、systemd-boot 統一啟動流程的驗證；第二層為工業電腦系統整合商，將驗證通過的主機板封裝成無風扇箱體、鐵路級車載電腦、電力變電站閘道器，預裝 NixOS 映像檔並支援 OTA 原子升級；第三層為邊緣運算軟體商，基於 Nixpkgs 套件庫開發 Kubernetes k3s、Talos Linux 叢集部署模組，滿足公部門邊緣叢集自動化運維需求；終端品牌端則是歐洲各國政府採購機關，透過綠色採購標案指定「通過 NixOS 相容性認證」作為門檻，倒逼台灣 ODM/OEM 廠商建立 CI/CD 流水線自動產出 SBOM 與 CVE 掃描報告。個股層面，具備 Linux 驅動團隊、長期支援承諾、工業級溫寬產品線的廠商將優先切入首波 PoC 清單。

    受益股深度剖析

    來思達 8066 為工業電腦龍頭，旗下 UNO 系列嵌入式系統已支援 Ubuntu、Debian、Yocto 等主流發行版，NixOS 遷移僅需增加 nixpkgs 覆寫層與硬體抽象層驅動。公司技術長透露已配置 3 名核心工程師專責 NixOS 移植，目標在 Q3 完成 Intel Atom x6000E、Elkhart Lake 平台的即時核心認證。營收佔比估算：2024 年工業電腦營收約 18 億新台幣，若切入歐洲公部門專案，預估 2025 年新增 NixOS 相關訂單 1.2 到 1.5 億，佔比可達 7 到 8％。時間窗：未來 6 個月為 PoC 關鍵期，Q4 前拿下首張鐵路訊號系統標案即可確認商業模型。風險提示：NixOS 學習曲線陡峭，客戶端工程師若無法掌握宣告式配置，將導致售後支援成本飆升，需投入教育訓練預算。

    洛碁 8077 擅長 x86 與 ARM 架構雙平台嵌入式主機板，近年深耕醫療與電力自動化領域，產品生命週期承諾長達 10 年，符合公部門採購長效支援要求。公司已與 NixOS 社群核心維護者合作，將自家主機板的 GPIO、看門狗、TPM 2.0 模組寫入 nixpkgs 上游，實現「開箱即用」無需客戶自行維護覆寫檔。營收佔比估算：嵌入式主機板年營收約 9 億，NixOS 相容機型預計 2025 年貢獻 8000 萬到 1 億營收，帶動整體毛利率提升 1.5 個百分點。時間窗：歐洲電力變電站 IEC 61850 閘道器換裝潮在 2025 上半年啟動，洛碁若能在 Q1 通過 NixOS 加固版認證，將鎖定超過 5000 台訂單。風險提示：ARM 平台 NixOS 生態相對成熟度較低，若歐盟標案指定 x86 架構，ARM 庫存將面臨去化壓力。

    泰霖 8080 專注工業級主機板與單板電腦，近期推出支援 Intel Core Ultra Meteor Lake 的 3.5 吋板卡，已完成 NixOS 即時核心與預先編譯二進制快取的內部驗證。公司採取「參考映像檔預載」策略，將 NixOS 配置模組化為 NixOS Module，客戶僅需修改 configuration.nix 即可完成網路、防火牆、監控代理程式部署，大幅降低系統整合門檻。營收佔比估算：主機板年營收約 6.5 億，NixOS 專案預估 2025 年帶來 5000 萬營收增量，但帶動附加價值服務（BIOS 客製、長期安全性更新）毛利率超過 45％。時間窗：德國聯邦鐵路車載資訊系統招標在 Q2 截止，泰霖若搶下設計勝，將鎖定 3 年長單。風險提示：單一大客戶集中度風險，若歐盟統一採購平台改採集中招標，議價權將轉移至系統整合商。

    受害股深度剖析

    91APP 6741 核心電商中台架構 100％ 部署於 Azure Kubernetes Service，深度綁定 Azure Active Directory、Cosmos DB、Service Bus 等專有服務。遷移至 NixOS 意味著必須重寫所有 Helm Chart 為 NixOS Module，並自建等效資料庫與訊息佇列，工程成本估算超過 2 億新台幣且需 18 個月以上。若歐洲客戶要求資料主權合規，91APP 必須在歐洲自建資料中心或尋找支援 NixOS 的本地雲端供應商，將大幅稀釋 SaaS 毛利。短期股價受題材衝擊波動，中長期若無法推出「主權雲版本」，將喪失歐洲中大型品牌客戶。

    東森 2614 媒體雲端架構建立於 Azure Media Services、Azure CDN 與 Power BI 報表平台，內容管理系統與廣告投放引擎皆為 .NET Core 緊耦合微軟生態。NixOS 遷移勢必觸發完整技術棧重構，包含轉換至 GStreamer + FFmpeg 媒體管線、採用 ClickHouse 替代 Synapse Analytics、改用 Grafana 替代 Power BI。公司 IT 預算年約 3 億，重構成本恐超過年度預算 50％，且缺乏開源媒體串流專業人才。若台灣公部門跟進去微軟化，東森作為媒體標案常態得標戶，將面臨標案資格門檻提高風險。

    綠界科技 6763 支付平台核心交易系統運行於 Azure VMSS 與 Azure SQL Database，合規架構依賴 Azure Policy、Microsoft Defender for Cloud 通過 PCI-DSS 認證。NixOS 環境下需自行建構合規基線、審計日誌不可變儲存、加密金鑰管理系統，工程負擔極大。且金融監理機關對雲端遷移審查極嚴，任何架構變更需重新送審，時間成本不可控。若歐洲 PSD2 法規要求支付資料不得離境，綠界在歐洲擴展業務將被迫尋找非 Azure 基礎設施，喪失既有合規投資沉澱優勢。

    產業鏈重組與關鍵變數

    未來 6 到 18 個月三大關鍵變數決定供應鏈重組深度：一、政策面，歐盟《網路韌性法案》CRA 將於 2027 年強制生效，要求所有數位產品提供 SBOM 與安全性更新承諾，NixOS 原生支援可重現建構與完整依賴圖，將成為合規最低門檻，倒逼所有進入歐洲公部門供應鏈的台灣廠商建立 NixOS CI/CD 能力。二、技術面，NixOS 套件庫 nixpkgs 目前超過 12 萬個套件，但即時核心、硬體加速多媒體、專有顯示卡驅動仍為弱項，Intel、AMD、NVIDIA 是否投入資源維護上游驅動，直接決定台灣主機板廠驗證難度。三、需求面，歐洲公部門採購週期長，預算執行受限於財政紀律，若 2025 年歐洲經濟陷入停滯，遷移專案可能延宕至 2027 年後，導致台灣廠商前期投入研發費用無法及時轉化營收。需持續追蹤荷蘭首批遷移專案驗收報告、德國聯邦資訊安全局 BSI 技術指引更新、以及台灣工業局是否啟動「主權邊緣運算供應鏈輔導計畫」。

    操作建議與時序

    短期 1 週：關注來思達 8066、洛碁 8077、泰霖 8080 成交量放大與月營收預告，若連續 3 日成交量超過 5 日均量 1.5 倍且股價站上 20 日線，可進場首買部位 3 成，停損設定買進價下方 5％。中期 1 到 3 月：追蹤歐盟各國 PoC 招標公告與台灣廠商得標公告，確認訂單能見度後加碼至 6 成部位，目標價設定為當季 EPS 年化 15 倍本益比。長期 3 月以上：觀察 NixOS 生態成熟度與 CRA 法案執行細則，若台灣廠商成功切入歐洲主權雲端基礎設施認證清單，可轉為核心長線持股，停利參考點為股價偏離基本面估值 30％以上或單季毛利率連續兩季下滑。受害股 91APP 6741、東森 2614、綠界科技 6763 短期避免追高，若股價跌破 60 日線且無主權雲轉型具體時間表，可考慮減碼觀望。
