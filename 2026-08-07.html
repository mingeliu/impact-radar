I. AMD 併購 Taalas，把 AI 模型直接刻進矽晶圓

AMD 宣布收購 AI 晶片新創 Taalas，技術核心是把模型權重直接蝕刻進矽晶圓，做成所謂的模型專用積體電路（MSIC），不再靠 HBM 暫存模型權重。Taalas 第一顆測試晶片 HC1 就是用台積電 6nm 製程生產的，跑 Llama 3.1 8B 每秒 16,960 tokens，比 Nvidia GPU 快 48 倍。AMD 計畫把 Taalas 加速器和 Instinct Helios 機架搭配，用 GPU 處理 prompt、用 Taalas 晶片做 token 生成。交易預計第四季完成，待監管批准。

核心影響：AMD 併 Taalas 等於押注「模型固化進硬體」這條路，台積電的先進和成熟製程都受惠，但長期 Nvidia GPU 供應鏈面臨推理市場份額被瓜分的風險。

II. Qwen3.8 Max 登頂 agentic index，中國 AI 模型彎道超車

阿里巴巴旗下的 Qwen3.8 Max 在 Artificial Analysis 的 agentic index 評比中登上第一名，超越所有現有模型。這代表中國 AI 模型在 agent 應用能力上已經不只是追趕，而是領先。對台灣供應鏈而言，模型推陳出新的速度加快只會讓推理算力需求更強，不管模型是美國還是中國做的，最後晶圓和伺服器都是台廠在做。

核心影響：中國模型能力登頂加速全球 AI 競賽，推理算力需求只會更強，台廠在硬體端不改受益格局。但要注意的是，模型能力來自中國代表美國可能加碼出口管制，反而讓供應鏈更複雜。

III. 4 萬次遊戲測試：人類放行 AI agent 指令，漏掉三分之一威脅

Scale X 發布研究，從 4 萬次遊戲、41 萬次放行決策的數據中發現，人類在扮演 AI agent human-in-the-loop 時，平均漏掉三分之一的威脅指令。最危險的是偽裝成 npm run 的指令，漏掉率高達 64.7%；資料竊取類指令漏掉率 33.4%，scope violation 漏掉率 35%。7% 的玩家直接放行所有指令。這代表 AI agent 的 human-in-the-loop 安全機制遠不如預期，企業必須投資自動化的 agent 權限管控和資安方案。

核心影響：AI agent 安全是企業導入的最大風險點，人類把關證明不夠用，自動化權限管控和沙箱隔離方案需求只會更強，台灣資安整合服務商訂單動能升溫。
